Introduction to Booleans

Booleans represent the two logical states true and false. In this category, you will assign Boolean values, convert other types, and explore how JavaScript treats truthy and falsy values.

Boolean values and expressions

const isReady = true;
console.log(isReady);
console.log(5 > 3);

Comparisons produce Boolean results. Conversions can reveal whether values such as zero, an empty string, or null are truthy or falsy.

console.log(Boolean(0));
console.log(Boolean('CodeCraft'));
