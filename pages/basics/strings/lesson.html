Introduction to Strings

Strings are sequences of text. In this category, you will create and combine strings, inspect their length and characters, format values with template literals, change letter case, and search text.

Concatenation, length, and indexing

const first = 'Code';
const second = 'Craft';
const word = first + second;
console.log(word.length);
console.log(word[0]);

Joining strings creates longer text. A string's length counts its characters, and indexes start at zero.

Template literals

const name = 'Ada';
const greeting = `Hello, ${name}!`;
console.log(greeting);

Case and searching

const message = 'Learn JavaScript';
console.log(message.toUpperCase());
console.log(message.includes('JavaScript'));

Case-conversion methods return new strings. Searching with includes() is case-sensitive.
