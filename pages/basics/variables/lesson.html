Introduction to Variables

Variables give names to values so a program can read and update information. In this category, you will practice declaring variables, assigning values, and using those values in JavaScript.

Declare and use values

let score = 5;
score = 8;
const learner = 'Ada';
console.log(score);
console.log(learner);

Use let when a variable needs to be reassigned. Use const when its binding should stay the same. console.log() prints a value so you can inspect it.
